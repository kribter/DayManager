DayManager 使用说明（先看这个，一分钟）

0. 先看系统要求
   Windows 10 版本 1809（2018 年 10 月更新）及以上，64 位。
   怎么确认：Win+R 输入 winver，版本号 ≥ 1809 就行。
   版本太旧的话安装程序会直接提示，不会装完打不开。

1. 怎么装 / 怎么卸
   装：双击 DayManager-Setup.exe，一路 Next。第二步「选择安装位置」可以自己改成
      任何文件夹（点「浏览…」挑，或直接手打路径）。默认装在你自己的用户目录下，
      不弹管理员权限、不改系统设置。装完在开始菜单里找「DayManager」。
   卸：开始菜单 → DayManager → 卸载 DayManager
      （或 Windows 设置 → 应用 → DayManager → 卸载）。
      卸载不会删掉你的日程数据，那个单独存在 %LOCALAPPDATA%\DayManager 下。

2. 怎么启动
   从开始菜单（或桌面快捷方式，安装时勾了才有）打开。
   第一次打开可能要等二三十秒：它会自己把后台服务拉起来，后台第一次启动要预热，
   之后每次打开都很快。

3. Windows 会弹一个蓝色警告（SmartScreen）
   点「更多信息」->「仍要运行」。
   这个程序没有买代码签名证书（一年几千块），Windows 对没签名的程序一律这样提示，
   不是病毒。只在第一次运行时出现一次。

4. AI 对话要你自己填密钥
   打开后 -> 底部「时间」页 -> 「设置 >」 -> 「AI 接入」，填你自己的大模型 API Key。
   不填也能用：记日程、勾完成、看统计都正常；只有“跟 AI 说话让它帮你排”这类用不了。
   密钥只存在你自己电脑的系统凭据区（Windows 是注册表），不会跟着这个压缩包发给别人。

5. 你的数据存哪
   %LOCALAPPDATA%\DayManager\daymanager.db
   想备份就定期复制这个文件。删掉程序文件夹不会删掉数据。

6. 怎么彻底退出
   右下角托盘图标 -> 右键 -> 退出。
   关掉窗口只是藏到托盘，它还在后台记着你的使用时长（那是它的主要功能之一）。
